01 · FULL-STACK

SecureTask Manager

React (Vite) · Node.js · Express · MongoDB · Jest · GitHub Actions

  • Built a multi-user task manager end to end, with a REST API and user-scoped CRUD so one account cannot read or change another user's tasks.
  • Implemented bcrypt password hashing, expiring JWTs, authentication rate limiting and server-side validation that rejects unknown fields such as a client-supplied user ID.
  • Hardened the API with Helmet security headers, size-limited JSON bodies, a CORS origin allowlist and environment checks at startup.
