## Run locally

No build tools or package installation are required.

1. Clone the repository.
2. Open `index.html` in a browser, or start a local static server from the repository root.

```bash
git clone https://github.com/aathal08/Resume-Page.git
cd Resume-Page
python -m http.server 8000
```

Visit http://localhost:8000.

## Deployment

The site is a static HTML, CSS and JavaScript project. GitHub Pages can publish it directly from the `main` branch and repository root.

## Certificates

Certificate PDFs are stored in [`certificates/`](certificates/). The certificate page links only to files currently present in the repository. See [the certificate inventory](certificates/README.md) for details.

## Maintenance

- Keep project descriptions accurate and link to the relevant source repositories.
- Add certificate PDFs to `certificates/` and update the portfolio link and inventory together.
- Keep role-specific resumes focused; this portfolio intentionally presents a broader overview.
